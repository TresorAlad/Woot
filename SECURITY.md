# Securite - Woot

Woot derive de Chatwoot (MIT). Pour signaler une vulnerabilite sur ce depot :

- Ouvrir une issue privee sur [TresorAlad/Woot](https://github.com/TresorAlad/Woot/security/advisories/new)
- Ne pas publier de details exploitables en public avant correction

Pour les vulnerabilites upstream Chatwoot, consulter aussi le processus officiel Chatwoot.

## Versions supportees

| Version | Support |
|---------|---------|
| main (derniere) | Oui |
| autres | Non |
